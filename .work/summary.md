What: Oak, a desktop Git GUI (Electron, React 19, TypeScript) that runs the user's installed git CLI.
For: developers who want everyday Git (stage, commit, branch, history, merge) done simply, keyboard-first, without a heavy IDE.
Goal: people finish common Git tasks easily and dependably; the same action behaves the same everywhere.
Platforms: Windows 11 primary, Linux experimental, macOS untested.
Out of scope: a Git library, IDE features, docking or saved layouts, permanent UI without a concrete workflow benefit.
Done means: typecheck, lint, format and tests pass, the change is verified in the real app, and the wk plan is current.
