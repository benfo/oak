# Code of Conduct

Oak is a place for friendly, practical collaboration on a Git client.

## Expected behaviour

- Be respectful and assume good intent.
- Give and accept constructive feedback.
- Keep discussion focused on the work.

## Unacceptable behaviour

- Harassment, insults, discrimination or personal attacks.
- Publishing other people's private information.
- Spam, or repeatedly pushing for changes the maintainer has declined.

## Enforcement

The maintainer may edit or remove comments, issues and pull requests, and may block anyone who breaks these rules. To report a problem, use the **Security** tab's private reporting or contact the maintainer through their GitHub profile.

This policy applies to all project spaces: issues, pull requests and any other discussion about Oak.
