# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**.

Include the Oak version, your operating system, and steps to reproduce. You can expect an acknowledgement, and a fix or an explanation, as soon as the maintainer is able. Oak is maintained by one person, so response times are best effort.

## Supported versions

Only the latest release receives fixes.
