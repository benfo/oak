Branch comparison

without checking out.

Review what a branch introduced since it branched from its target. Select an earlier commit to review the branch at that point. Your working tree stays in place.

02 / Diff layouts

Inline or
Side by side.

View additions and deletions in one column, or compare before and after in two columns. Both layouts include syntax colours and word-level change highlighting.

Before and after, aligned. Follow a replacement across both columns.

One continuous diff. Follow additions and deletions in a single column.

Switch layouts in Oak with Ctrl + Shift + D, keeping your place. Show more or less surrounding code with the context buttons in the diff header, or the whole file with Ctrl + Shift + W.

03 / Staging

Stage files,
hunks or lines.

Select the changes to include in a commit. The remaining changes stay unstaged.

Review staged and unstaged changes beside your commit message. If you commit with nothing staged, Oak asks whether to stage the changed files first; new files are included only if you tick the box.

Try staging selected lines →

04 / Command palette

Find commands
by typing.

Press Ctrl Shift P and type part of a command name. Use the arrow keys to select a result and Enter to run it.

The palette includes branch operations, comparisons, stash actions, diff controls, history scope (for example, the current branch's own commits without main's history), opening a branch's pull request page and preferences. Commands show their keyboard shortcuts where available.

Try the command palette →

05 / Focus mode

Give the diff
the whole window.

Press F11 to expand the focused history graph or code area. Press it again to restore your layout, focus and pane sizes.

In expanded history, Enter opens the selected commit's code. While reading a diff, Alt PageUp and Alt PageDown move between files. The toolbar's expand button does the same as F11.

Keyboard navigation

Navigate lists, diffs and menus.

Move between history, files and diffs using the keyboard. Search lists with / or Ctrl+F. Optional h/j/k/l keys work alongside the arrows in lists, diffs and menus.

Git setup

Uses your installed Git.

Oak runs the Git CLI. It uses your existing credentials, configuration, hooks and Git LFS setup.

The working tree refreshes automatically when local files change and when you return to the window. Fetch checks for changes on the remote.
