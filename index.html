Compare branches
without checking out.

Review what a branch introduced since it branched from its target. Select an earlier commit to review the branch at that point.

Your working tree stays in place while you compare.

  1. Select a target

    Compare against main, a release branch or another feature branch.

  2. Open a changed file

    Select a file to read its diff alongside the commit history.

  3. Step back to an earlier commit

    Select an earlier commit to see the branch’s changes up to that revision.

Inline or
side by side.

View additions and deletions in one column, or compare before and after in two columns. Both layouts include syntax colours and word-level change highlighting.

Before and after, aligned. Follow a replacement across both columns.

One continuous diff. Follow additions and deletions in a single column.

Switch layouts in Oak with Ctrl + Shift + D, keeping your place. Show more or less surrounding code with the context buttons in the diff header, or the whole file with Ctrl + Shift + W.

Stage files,
hunks or lines.

Select the changes to include in a commit. A click selects exactly the line shown, and the remaining changes stay unstaged.

Review staged and unstaged changes beside your commit message. If you commit with nothing staged, Oak asks whether to stage the changed files first; new files are included only if you tick the box.

Find commands
by typing.

Press Ctrl Shift P and type part of a command name. Use the arrow keys to select a result and Enter to run it.

The palette includes branch operations, comparisons, stash actions, diff controls, history scope (for example, only the current branch's own commits), opening a branch's pull request page and preferences. Commands show their keyboard shortcuts where available.

Give the diff
the whole window.

Press F11 to expand the code area. Press it again, or Escape when nothing else is selected, to restore your layout, focus and pane sizes.

While reading a diff, Alt PageUp and Alt PageDown move between files. The toolbar's expand button does the same as F11.

Changed files
as a list or a tree.

Press V in a file list, or use the button in its header, to group changed files by folder. It applies to Changes and to a commit's files in History, and your selection stays in place when you switch.

Small behaviours that save steps.

History scope

Show only the current branch's own commits, without the default branch's history. Switch to the full ancestry, or add a target branch, from the History scope menu.

Resize with the keyboard

Press Shift Alt ← → ↑ ↓ to move the divider of the pane you are in. Dragging a divider still works.

File history

Choose "Show file history" from a file's menu, or from the command palette, to filter the History graph to the commits that touched that file. Stepping through them shows only that file's diff.

Conflicts open in your merge tool

When a merge stops with conflicts, Oak switches to Changes and shows a banner. Open the conflicted files one after another in the merge tool set in Preferences. Marking a file resolved warns you if conflict markers remain.

Navigate lists, diffs and menus.

Move between history, files and diffs using the keyboard. Tab steps through the controls inside a pane, such as the buttons in a file list. F6 switches panes. Search lists with / or Ctrl+F. Optional h/j/k/l keys work alongside the arrows in lists, diffs and menus.

Uses your installed Git.

Oak runs the Git CLI. It uses your existing credentials, configuration, hooks and Git LFS setup.

The working tree refreshes automatically when local files change and when you return to the window. Fetch checks for changes on the remote.

What may come next.

These are ideas on the list, not promises. They have no dates, and the order can change as I use Oak and hear from others.

Smoother conflicts

Say which side is ours and theirs, handle modify and delete conflicts, and bring Pull and Rebase conflicts into the same flow.

Interactive rebase

Reorder, squash, edit and drop commits from the history graph.

Blame

Find who last changed a line and jump to the commit that did.

Pull request review

Fetch a pull request's branches and open the comparison in Oak. Comments and approvals would stay on the provider's website at first.

Diff readability

Hide whitespace and line-ending differences, and fold long unchanged regions so substantive edits stand out.

Open and preview more files

Preview images, PDFs and other safe files, and open anything else in its default app or show it in its folder.

Git command log

A list of every command Oak ran, with its output.

Signed installer

Code-sign the Windows installer so it no longer needs unblocking.

Missing something you use every day? Open an issue.

Windows

Windows 11 · x64 installer

Download for Windows ↓

Requires Git on PATH.

The installer is not code-signed yet, so Windows may block the download or show a SmartScreen warning. Right-click the file, choose Properties and tick Unblock, or run Unblock-File .\Oak-Setup-0.1.14.exe in PowerShell. In SmartScreen, choose More info, then Run anyway.

Linux

x64 · Debian package or AppImage

Download for Linux ↓

Experimental. Choose the .deb or the AppImage on the release page. The Debian package is smoke-tested on Ubuntu 24.04 and installs Git as a dependency. For AppImage, install Git and mark the downloaded file as executable.

macOS is untested; no download is available yet.
