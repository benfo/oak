Everyday repository workflows

Branch navigation

Keep your current branch in view.

Your current branch and recently checked-out branches appear above the full branch list.

  • Filter branches by typing their names.
  • Sort by name or latest commit.
  • Hide branches with a gone upstream while keeping the current branch visible.

Branch review

Comparison controls appear when you use them.

Start from a branch context menu or the command palette. The target and comparison mode sit alongside the changed files and diff.

  • Choose the target branch; it does not have to be main.
  • Review changes since the common ancestor or compare branch snapshots.
  • End the comparison to return to the regular commit view.

Keyboard navigation

Use consistent keys across panes.

Navigate from history to files to the diff with the keyboard. Search the command palette or shortcut reference when you need an action.

Downloads and Git setup

Oak runs your installed Git CLI. Your credentials, configuration, hooks and Git LFS remain part of that setup.

Install Git and make it available on your PATH before opening a repository.
